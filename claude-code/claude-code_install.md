# Claude Code インストール方法

## AWS EC2 Rocky Linux 9へのインストール方法

```bash
# インストール方法
curl -fsSL https://claude.ai/install.sh | bash

# インストール確認
claude --version
## 実行結果
2.1.195 (Claude Code)
```

## Claude Code ログイン方法

```bash
# ログイン方法
claude login

```
